# نظام إدارة مخزن مستلزمات الكهرباء — الإصدار 10

نظام ويب لإدارة مخزن قطع الكهرباء: أصناف، أذون وارد وصرف، جرد، تسعير، وتقارير —
يعمل من رابط واحد، ويشترك فيه كل المستخدمين على نفس قاعدة البيانات في نفس اللحظة.

## ما الذي تغيّر عن الإصدار السابق؟

| الإصدار 9 | الإصدار 10 |
|---|---|
| ملف Excel محلي على جهاز واحد | قاعدة بيانات PostgreSQL مشتركة على Supabase |
| كل مستخدم عنده نسخته | الكل على نفس البيانات، والتعديل يظهر فورًا عند الجميع |
| كلمات المرور مكتوبة داخل الملف | نظام مصادقة حقيقي مع تشفير وجلسات |
| الصلاحيات في الواجهة فقط | الصلاحيات مفروضة داخل قاعدة البيانات (RLS) |
| رقم الإذن = آخر رقم + 1 (يتعارض مع مستخدمين متزامنين) | عدّاد على الخادم لا يكرّر رقمًا أبدًا |
| ملف واحد 4000 سطر | وحدات منفصلة، كل ملف مسؤولية واحدة |

## البدء السريع

1. **أنشئ قاعدة البيانات** — [`docs/01-setup-supabase.md`](docs/01-setup-supabase.md)
2. **انشر الواجهة على GitHub Pages** — [`docs/02-deploy-github.md`](docs/02-deploy-github.md)
3. **انقل بياناتك القديمة** — افتح `tools/import.html` بعد النشر
4. **علّم الفريق** — [`docs/03-user-guide.md`](docs/03-user-guide.md)

## بنية المشروع

```
index.html              الصفحة الوحيدة التي تُفتح
assets/css/             التنسيقات (الواجهة، شاشة الدخول، الطباعة)
src/
  config.js             رابط قاعدة البيانات والمفتاح العام
  main.js               التشغيل والتنقّل بين الشاشات
  core/                 أدوات مشتركة: DOM، تنسيق، تحقق، تنبيهات، حالة
  data/                 الاتصال بقاعدة البيانات والاستعلامات والتحديث اللحظي
  auth/                 الدخول والصلاحيات
  views/                الشاشات: لوحة القيادة، الأصناف، الأذون، السجل، التقارير، التسعير، الجرد، الإعدادات
sql/                    ملفات إنشاء قاعدة البيانات (تُشغَّل بالترتيب)
tools/import.html       أداة نقل بيانات Excel القديمة (مرة واحدة)
docs/                   أدلة التركيب والنشر والاستخدام
```

## التكلفة

الخطة المجانية في Supabase تكفي هذا الحجم بوضوح: 500 ميجابايت قاعدة بيانات
(الأصناف والحركات نصوص وأرقام — عشرات الآلاف من الحركات أقل من 50 ميجابايت)،
وGitHub Pages مجاني بالكامل.

> تنبيه واحد: المشروع المجاني في Supabase يدخل في سبات بعد **٧ أيام** بدون أي استخدام،
> ويعود بالضغط على زر في لوحة التحكم. استخدام يومي عادي يعني أن هذا لن يحدث.
