# ٢ — نشر الواجهة على GitHub Pages

النتيجة: رابط ثابت مثل `https://mahmoud.github.io/mp-store/` يفتحه أي شخص من المتصفح.

## الطريقة الأولى: من المتصفح (بدون أوامر)

1. افتح <https://github.com> → **New repository**.
   - الاسم: `mp-store`
   - النوع: **Public** (الـ Pages المجاني للمستودعات العامة)
   - لا تضف README (موجود عندنا بالفعل)
2. في صفحة المستودع الفارغ اضغط **uploading an existing file**.
3. اسحب **كل محتويات المجلد** (وليس المجلد نفسه): `index.html`, `assets/`, `src/`, `sql/`, `tools/`, `docs/`, `README.md`, `.nojekyll`.
4. اكتب في خانة الرسالة: `الإصدار الأول` ثم **Commit changes**.
5. **Settings → Pages**:
   - Source: **Deploy from a branch**
   - Branch: `main` والمجلد `/ (root)` ثم **Save**.
6. انتظر دقيقة، ثم حدّث الصفحة — سيظهر الرابط في أعلى صفحة Pages.

## الطريقة الثانية: من سطر الأوامر

```bash
cd mp-store
git init
git add .
git commit -m "الإصدار الأول"
git branch -M main
git remote add origin https://github.com/<اسمك>/mp-store.git
git push -u origin main
```

ثم فعّل Pages من **Settings → Pages** كما في الخطوة ٥ أعلاه.

## قبل الرفع: تأكد من هذه النقاط

- [ ] `src/config.js` يحتوي على `SUPABASE_URL` و`SUPABASE_ANON_KEY` الصحيحين.
- [ ] الملف `.nojekyll` موجود في الجذر (يمنع GitHub من تجاهل الملفات التي تبدأ بـ `_`).
- [ ] لا يوجد أي مفتاح `service_role` في أي ملف.

## تحديث النظام لاحقًا

أي تعديل: ارفع الملف المعدّل مكان القديم (أو `git push`)، والرابط يتحدّث خلال دقيقة.
اطلب من المستخدمين عمل **Ctrl + Shift + R** مرة واحدة بعد أي تحديث لتجاوز الذاكرة المؤقتة.

## اختصار على سطح المكتب

على أجهزة المخزن: افتح الرابط في Chrome → قائمة النقاط الثلاث →
**Cast, save and share → Install page as app**. يصبح للنظام أيقونة مستقلة تفتح بدون شريط المتصفح.

## سؤال متكرر: هل الرابط العام يعني أن أي أحد يرى البيانات؟

لا. الرابط يفتح **الواجهة** فقط. أي بيان لا يظهر إلا بعد تسجيل دخول صحيح،
وقاعدة البيانات ترفض أي طلب من غير مستخدم مسجّل — هذا ما تفعله سياسات RLS في `03_security.sql`.

## بديل لو أرادت الشركة ألا يكون المستودع عامًا

- **GitHub Pages للمستودعات الخاصة** متاح في خطة GitHub Team المدفوعة.
- أو استضف الواجهة على **Cloudflare Pages** (مجاني ويدعم المستودعات الخاصة).
- أو ضع الملفات على خادم IIS/Apache داخلي في الشركة — الملفات ثابتة ولا تحتاج أي خادم تطبيقات.
